### Skill: research with web citations

For any current, external, or time-sensitive fact:

1. **Search.** Call `web.search` with a precise query. Scan titles + snippets for
   the most authoritative, recent sources.
2. **Verify before citing.** Call `web.fetch` on the 1–3 best results and read the
   actual text — don't cite from a snippet alone; snippets mislead.
3. **Cite every external claim** with its URL. If two sources disagree, say so and
   prefer the more authoritative / more recent one.
4. **Never answer from memory** for facts that can change (prices, news, versions,
   people's current roles). If search returns nothing usable, say you couldn't
   verify it rather than guessing.
5. **Stay on task.** Pull only what the user's question needs; summarise concisely
   with the citations inline.
