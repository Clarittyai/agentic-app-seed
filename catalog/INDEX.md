## Tools (catalog)

- **`knowledge.ingest`** (standalone) — Add text to the app's knowledge base for the current user so it can be retrieved later with knowledge.search. Use for notes, extracted facts, or app data the app generates.
- **`knowledge.search`** (standalone) — Semantically search the app's knowledge base (the current user's uploaded documents + app data, embedded server-side) and return the most relevant passages to ground an answer on.
- **`llm.classify`** (standalone) — Classify a piece of text into exactly one of the provided labels using the LLM proxy. The chosen label is snapped to one of the options so workflow branching is safe.
- **`llm.draft`** (standalone) — Draft a short message (email reply, post, note, summary blurb) from context in a given tone, using the LLM proxy. Returns text only — pair with a human-in-the-loop approval step before sending anything.
- **`llm.extract`** (standalone) — Extract structured fields from free text into a JSON object using the LLM proxy. Pass the field names (and optional descriptions) you want pulled out.
- **`llm.rank`** (standalone) — Rank/prioritize a list of items against a stated criterion using the LLM proxy. Returns the items ordered most-important first, each with a score and a one-line reason.
- **`llm.summarize`** (standalone) — Summarize a list of texts into a short digest using the LLM proxy.
- **`memory.recall`** (standalone) — Recall the current user's most relevant remembered facts/preferences for a query. Call at the start of a run to personalise behaviour with what the app already knows about the user.
- **`memory.save`** (standalone) — Remember a durable fact or preference for the current user, persisted across runs. Pass a stable memKey to overwrite that memory instead of accumulating duplicates.
- **`web.fetch`** (standalone) — Fetch a web page's readable text (e.g. a URL returned by web.search) so the agent can read and cite the source. Platform capability; server-side fetch is SSRF-guarded.
- **`web.search`** (standalone) — Search the live web for current, external facts and return ranked results (title, url, snippet). A platform capability — no integration needed. Use for anything time-sensitive or outside the app's own data.
